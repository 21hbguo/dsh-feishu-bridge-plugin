### 1.2 数据流

**入站（飞书 → DSH）**：`channel 'message'` 事件 → `runtime.handle()`（index.ts:146-148, 786-832）：
1. 过滤：机器人自消息跳过（787-788）、群聊未 @ 跳过（789）
2. `stripMentions` 剥离 @ 提及（791, text.ts:8-14）；空文本丢弃
3. 先消费待答自由文本（`questions.answerPendingFreeText`，796）
4. 前置解析强制模式：`/squeeze <内容>`（强制排队）、`/steer <内容>`（强制插队）、`/ai <内容>`（显式注入），均旁路批处理（802-818）
5. `/` 开头 → `enqueueCommand` 进独立命令队列 → `runCommand`（819-821）
6. 普通消息 → 批处理窗口（`batcher.push`，831）或直接 `processNormalText`（828）

**回合执行（核心）**：`processNormalText` → `enqueue`（per-chat Promise 链串行 + 看门狗 race，444-472）→ `thinkTurn`（481-569）：
- `ensureAgent`（365-413）：`agents.get` → 持久化命中 `agents.resume` → 否则 `agents.create`（meta: cwd/agentPreset，agentOptions: 模型偏好，setup: installEffortPref），`whenIdle` 后才首次 followup
- `agent.followup`（queue 模式）/ `agent.steer`（steer 模式）注入 `createUserMessage`（source.kind='user'，与 web 同语义）
- `session/event` 监听收集 `assistant/chunk` text-delta、`tool/call`、`turn/end`；按 endedTurn 过滤迟到 chunk（562-564）
- 流式分支：`channel.stream` markdown controller 增量 append（SDK 层 40ms/12 字符节流）→ 完成后 `appendTokenFooter` 打补丁（629-638）

**出站（DSH → 飞书）**：流式卡片（`channel.stream`）/ 一次性卡片（`channel.send({card})`）/ 纯文本（`cmdReply`）。token 用量由 `assistant/message` usage 事件累计（322-327），回退 `tokenMeter.measure`（585-598）。

**交互帧（agent 提问/审批 → 卡片 → 回宿主）**：
- 问答：host `user-questions` provider mint rpcId → `apiProxy.events.mux` 推送 `question/requested` → 反查 chat 发 CardKit 卡 → 按钮 value 编码 `ask|rpcId|qIndex|optionIndex`（单选）/ `askm|…`（多选）/ `asksubmit|rpcId`（确认）→ 回调路由 → `api.respond(ClientResponse)` 提交 → `question/resolved` 撤卡；10 分钟 TTL reaper 撤卡并向 host 提交 cancelled（不悬挂 pending）
- 审批：`approval/requested`（host mint rpcId）→ 卡片 `appr|<approvalId>|allow|reject` → respond（回显 rpcId + approvalId + outcome）→ `approval/resolved`（无 rpcId，按 approvalId 撤卡）；YOLO 开时自动放行不弹卡；过期只撤卡不提交（客户端无 cancelled 分支）

## 附：优先补齐建议（Top 5）

1. **消息零丢失 Outbox + 入站补发（基准 #7 #8）**——可靠性根基：出站 JSONL + 幂等键 + 失败重发，入站 WAL + 启动对账，让「桥」真正可用作生产通道。
2. **入站多媒体（#11）**——飞书高频刚需：图片走视觉模型、文件有界文本提取，补上「静默丢弃」短板。
3. **卡片化命令 + 权限分级（#4 #3）**——把 /model 升级为单选卡片，新增 /permission（只读/工作区写/Full access）卡片命令，补上只读档。
4. **表情回执（#6）**——轻量高可见度：收到消息随机表情 + 回合完成打 DONE ✅；需同步在 setup addons 里申请表情权限（补 #1 缺口）。
5. **连接自愈增强（#9）**——probe 驱动受控重连 + 配额熔断（QuotaGovernor）+ 断连补偿；可选加分项：/doctor 诊断包（#13）与 Markdown→CardKit 结构化渲染（#14）。
