### 与 lark-link 原版的关键化用差异
1. **Outbox**：砍掉 OutboundEnvelope/RouteRef 抽象层，envelope 即投递单元（本机回复形状）；修复原版缺陷——deliver 抛错会把 envelope 卡在 sending 直到重启，本机折算为 retryable 失败进程内自愈。
2. **WAL**：记录形状精简为 {messageId, chatKey, text}（重放走 handle 旁路跳过入站过滤，不需要 chatType/sender）；prune 额外删除磁盘陈旧 seg 文件（原版只清内存，段文件无限累积）。
3. **启动对账时机**：原版在 supervisor 连接后执行，本机移到 connectChannel 首次连接成功分支——连接未就绪时补发只会产出错误通知。
4. **quota**：合并 recordConnect(ok) 单方法；不搬 supervisor 状态机；新增 lastAttemptAt() 与 chmod 0600 加固。
5. **command-router**：原版路由在入站管道层，本机命令表在 commands.ts 内 → 化用为「注入点模式」（setCommandsHost/setAgentFallback/setStatusExtra），未接线即现状，接线零回归。
6. **Markdown 卡片**：原版只做检测+单元素，本机做真结构化转换（表格用 div.fields 布局）+ 阈值/异常双降级。
